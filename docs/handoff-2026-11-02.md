## SSH e deploy

SSH funziona con la chiave del progetto. **Usare sempre bash**, non zsh:

```bash
bash -c 'source scripts/lib/remote.sh; prepare_remote "$PWD"; remote_ssh "hostname; uptime"'
```

Il primo errore `Connection refused` era transitorio, legato al carico
dell'host; un secondo errore era un `trap` zsh che cancellava la chiave
temporanea. `./scripts/deploy.sh` usa bash e funziona.

```bash
./scripts/deploy.sh --dry-run
./scripts/deploy.sh --apply
./scripts/verify.sh
./scripts/backup.sh
```

`deploy.sh` è dry-run di default. Non usare `docker compose down`, `prune`,
`--remove-orphans` o comandi globali: sull'host girano altri stack.
